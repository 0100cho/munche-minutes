# 문체위 실시간 속기

국회 문화체육관광위원회 회의의 실시간 AI 속기를 보는 정적 웹페이지입니다.

- 실시간 속기 자동 갱신(생중계 중 4초 간격), 정회·감사중지 표시
- 키워드 검색(쉼표로 여러 개, 띄어쓰기 무시), 일치 줄만 보기
- 화자 지정(숫자키 단축키, 호명 기반 자동 제안), 브라우저에 저장
- 회의록 양식/줄 단위 복사, 선택·검색 결과·전체 복사, TXT 저장
- 화자 이름 클릭 → 질문·답변 요지 AI 요약(각 100자 내외) 플로팅 창. Anthropic API 키를 브라우저에 입력해 사용(이 브라우저에만 저장)

데이터: 국회 인터넷의사중계 AI 자막 ([assembly-minutes](https://seoul-raphael.github.io/assembly-minutes/) 공개 API 경유).
AI 속기는 오류가 있을 수 있으니 인용 전 공식 회의록을 확인하세요.
